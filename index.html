alt

A Ruby client for the Realtor API.

Ruby gem · 2.0.0 · MIT · Source Reference RubyGems

01What it does

Give it a street address. It answers the facts Realtor states about that home, reached through RapidAPI: the numbers, the choices and the presence flags, each named by what it is.

property = Alt::Property.new address: '4352 Desert Park Ave', unit: nil,
  city: 'North Las Vegas', zipcode: '89085'

property.facts
# => { "Lot size" => 0.1837, "Living area" => 3000, "Bedrooms" => 5,
#      "Bathrooms" => 2, "Year built" => 1999, "Stories" => 2,
#      "Garage spaces" => 3, "Fireplaces" => 2,
#      "Property type" => "Single family", "Heating system" => "Forced air",
#      "Heating fuel" => "Natural gas", "Cooling" => "Central air",
#      "Roof" => "Asphalt shingle", "Construction" => "Brick",
#      "Sewer" => "Public", "Foundation" => "Slab", "Pool" => "Yes",
#      "Outdoor living" => "Yes", "Fence" => "Yes", "Sprinklers" => "Yes",
#      "Coordinate" => [36.2814, -115.1543] }

Realtor has no address-to-detail endpoint, so one call is two requests: /locations/v2/auto-complete resolves the address to a property id, and /properties/v3/detail answers the details. Alt::Error is raised when either fails, or when the address matches no property.

02How it benefits you

One name per fact.
Listings are written in whichever dialect their MLS uses. Warm Air, Forced Air and ForcedAir all answer Forced air. Forced Air, Natural Gas answers a heating system and a heating fuel. Anything the mapping does not name answers Other. The options were derived from 329 real enrichments, since the API's documentation does not describe these fields.
Nothing invented.
A fact the listing does not state is left out, never answered as a zero or a false. The response cannot tell “no pool” from “no mention of a pool”, and a value that says the second while meaning the first is worse than no value at all.
Nothing leaked.
Realtor also sends the street, an href whose slug is the address, the listing agent's name, email and phones, and a Street View URL carrying a live Maps key. An allow-list keeps all of it out. Coordinate is the one entry not meant for storage: pin the home on a map with it and drop it, since a precise coordinate kept beside a street address is personal data.
Nothing else to depend on.
The standard library and one file of Active Support. Ruby 3.2 or later.

03How to install

System-wide:

gem install alt

Or in a Gemfile, pinned to the current major:

gem 'alt', '~> 2.0'

~> major.minor means bundle update never crosses a breaking change.

Subscribe to the Realtor API on RapidAPI and set the key as ENV['RAPIDAPI_KEY']. The host, realty-in-us.p.rapidapi.com, is sent as X-RapidAPI-Host for you.
